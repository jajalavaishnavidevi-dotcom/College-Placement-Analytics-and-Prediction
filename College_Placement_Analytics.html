    Project

    College Placement Analytics — an interactive, single-page analytics and prediction tool built entirely with HTML, CSS and JavaScript. No backend, no external database: the entire pipeline, from column detection to model training, runs client-side in the browser.

    Objective

    To analyze historical student placement records and surface the patterns behind stronger outcomes — academic performance, skills, internships, and recruiter activity — so a placement cell or student can see, at a glance, what tends to correlate with getting placed, and estimate the likelihood for a new profile.

    Analytics covered

    • Overall placement rate and package statistics
    • Branch-wise placement performance
    • Company-wise recruitment activity
    • Package distribution across placed students
    • CGPA and academic-performance relationship with placement
    • Programming-skill association with placement
    • Year-on-year placement trends

    Data source & portability

    All figures, charts and model outputs on this dashboard are calculated directly from the loaded dataset — nothing is hard-coded or simulated. Use "Upload dataset" in the top bar to load a different, similarly structured spreadsheet; the dashboard re-detects the schema and re-analyzes it automatically.

    Model typeLogistic Regression

    Limitations

    Trained on a single institution's historical dataset. Correlations shown are observed associations, not proven causes, and results will shift as new data is uploaded. Not intended as a production admissions or hiring tool.
