# College Placement Analytics & AI Prediction Platform

An interactive web-based platform for analyzing college placement data and predicting student placement probability using machine learning.

## Features

- Placement Analytics Dashboard
- Company-wise Placement Analysis
- Branch-wise Placement Analysis
- Package Distribution
- CGPA vs Placement
- Skills vs Placement
- AI-Based Placement Prediction
- Individual Technical Skill Analysis
- Model Performance Evaluation
- Prediction Explainability
- What-If Analysis
- Interactive Data Explorer

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- 5-Fold Cross Validation
