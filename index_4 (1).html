    Project

    College Placement Analytics Dashboard — an interactive, single-page analytics and prediction tool built entirely with HTML, CSS and JavaScript, with the full machine-learning pipeline running client-side.

    Purpose

    To analyze historical student placement data, understand what is associated with placement outcomes, and provide an honest, leakage-free estimate of an individual student's placement likelihood — built for reliability, not just a high accuracy number.

    Methodology pipeline

    Preventing data leakage

    Only information that would realistically be known before the placement process is used as a model input. Placement Status (the target), the recruiting Company, Package received and Placement Date are always excluded from the feature set, even if a newly uploaded dataset contains them.

    Features excluded by project scope

    Diploma Percentage, Technical Score, Soft Skills Score and Communication Score are left out of both the model and the prediction form, even though they aren't leakage. They're composite, subjective assessment scores rather than concrete pre-placement facts, so keeping them out ensures every driver shown to a student — CGPA, attendance, a specific skill, an internship — is something they can point to and act on.

    Skill-based prediction

    Each programming language / technical skill found in the dataset is encoded as its own Yes/No feature — a student with Python + SQL is represented differently from one with Java alone, rather than collapsing everyone to a single "skills count" number. This lets the model (and the permutation-importance chart) show which specific skills are associated with placement, not just how many a student lists.
